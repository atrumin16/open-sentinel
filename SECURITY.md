# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security issue or vulnerability within OpenSentinel, please DO NOT open a public issue.
Instead, send an email to `atrumin16@gmail.com` with the details and reproduction steps. We will review and patch vulnerabilities promptly.
